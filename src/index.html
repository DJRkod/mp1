01 / about

A little about me

I'm a computer science student at the University of Illinois Urbana-Champaign. I like building things people can actually use: web pages that feel good at any screen size, small services I can host myself, and tools that turn a pile of data into something readable.

Recent coursework has taken me through web programming and text information systems, where my group fine-tuned BERT models for a retrieval project. Outside of class I maintain Jukeplox, a self-hosted party jukebox for Plex.

When I'm not at a keyboard I'm usually hunting for good coffee or arguing about what should be next in the queue.

Web app

Illini Course Planner

Planning four years of courses in a spreadsheet gets old quickly. The planner lets you drag courses between semesters and immediately see what that does to your credit load and which prerequisites you have just broken.

  • Drag-and-drop schedule built on plain DOM events
  • Prerequisite checks that explain what is missing, not just that something is
  • Plans saved locally, so there is nothing to sign up for

Website

Prairie Roasters

A single-page site for a small coffee roaster. The brief was simple: load fast on a phone in the shop, look like the bags on the shelf, and let the owners change the menu without calling me.

  • Hand-written, responsive layout with no CSS framework
  • Menu content kept in one easy-to-edit file
  • Keyboard and screen-reader friendly from the first draft

Open source

Jukeplox

Jukeplox turns a Plex music library into a party jukebox. Guests open a page on their phones and add songs to a shared queue, and the host decides where it plays.

  • Self-hosted: your library, your network, no accounts for guests
  • Plays to Chromecast, AirPlay, DLNA, or the speakers plugged into the server
  • Written in Python and built to be left running
